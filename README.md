# Traceva (QA-Web)

Traceva mengelola testcase, siklus pengujian, bug, bukti, dan laporan QA dalam satu workspace.

Setelah clone atau pull pertama di Windows, pasang Node.js yang disyaratkan, lalu buka **`setup-traceva.bat`**. Setup mengisi konfigurasi lokal, memasang dependensi dan Chromium, menyiapkan SQLite, serta memandu pembuatan Owner pertama.

[Guidebook Traceva](docs/traceva-guidebook.md) mencakup instalasi manual, pemecahan masalah, dan cara menggunakan setiap halaman.
